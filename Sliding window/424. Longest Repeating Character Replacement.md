This is NOT a "trivial" sliding  window question.
Here, we maintain a count of encountered characters in a map. Then using the no. of characters that occur the most, we check if our window is valid via;
`windowLength - maxCount > k`
What we're essentially checking is if we have the "budget" to swap out the rest of the characters to form a substring with repeating chars

```js

var characterReplacement = function(s, k) {
    // Frequency map to keep track of characters inside the active window
    let count = {};
    let windowStart = 0;
    let maxCount = 0;
    let maxLength = 0;

    // Expand the window one character at a time using windowEnd
    for (let windowEnd = 0; windowEnd < s.length; windowEnd++) {
        const char = s[windowEnd];
        
        // Add the current character to our frequency map
        count[char] = (count[char] || 0) + 1;
        
        // Update maxCount to find the most frequent character in our window
        maxCount = Math.max(maxCount, count[char]);

        // Calculate the total length of the current window
        const windowLength = windowEnd - windowStart + 1;

        // If mismatched characters exceed our replacement budget k,
        // the window is invalid and we must shrink it from the left
        if (windowLength - maxCount > k) {
            count[s[windowStart]]--;
            windowStart++;
        }

        // Record the largest valid window size we have seen so far
        maxLength = Math.max(maxLength, windowEnd - windowStart + 1);
    }

    return maxLength;
};
```

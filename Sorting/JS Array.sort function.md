Is typically Onlogn

Given an array 
`const nums = [5,9,21,1,2]`

Incrementing order. 
Notice how a-b looks like an upward slope lol
`nums.sort((a,b) => a-b)`
Res:
[    1,    2,    5,    9,    21 ]

**Decrementing order**
`nums.sort((a,b) => b-a)`
Notice how b-a looks like a slope going downwards lmao
Res:
[    21,    9,    5,    2,    1 ]

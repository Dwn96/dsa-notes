# Data Structures & Algorithms

A collection of implementations, notes, and practice problems covering core data structures and algorithms.

## Overview

This repository is designed to help strengthen understanding of foundational computer science concepts, including:

- Arrays and strings
- Linked lists
- Stacks and queues
- Hash tables
- Trees and binary search trees
- Heaps and priority queues
- Graphs and graph traversal
- Sorting and searching algorithms
- Dynamic programming
- Greedy algorithms
- Recursion and backtracking
